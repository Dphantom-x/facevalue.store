# FaceValue — "The Fusion" · Locked Shooting Script

_The chosen concept (B). ~45s · **1:1 (1080×1080)** master for X. Updated 2026-06-15 with the design-vs-record split and the 1:1 framing._

**Vibe:** a relatable-failure hook (a fan shut out) welded onto a clean, real proof core (the live gate). **Goal:** credibility + reach in one — and the deliverable owed to Valiron for their X feature, so the gate must be visibly real.

**The one rule:** 🎨 = you DESIGN it in Claude Design (the fictional "old way" screens). 📹 = you RECORD it real from the app (FaceValue + the gate). **Never design the gate** — the whole video rests on "not scripted."

**Three acts:** Act 1 The Pain (0–6s) → Act 2 The Proof (6–23s) → Act 3 The Product + Payoff (23–45s).

## Production checklist (pre-roll, in order)

1. **`npm run warm`** — warm Valiron and confirm a hot response (cold-starts 30–60s; a cold gate **hangs on camera**). Re-warm right before the `/simulation` take.
2. **`POST /api/dev/reset`** — clean demo state.
3. **`npm run dev`** — confirm `serverExternalPackages: ["better-sqlite3"]` intact (else DB routes 500).
4. *(optional)* **`npm run prove:valiron`** — confirm ALLOW on 25459 / DENY on 1226.
5. Browser: mobile viewport, hide notifications/bookmarks, clean seeded account.
6. **Capture the magic moment FIRST** while Valiron is warm.
7. Pre-stage a claimed ticket so `/tickets` has a QR and `/door` has a token to scan twice.
8. Confirm handles before the end card + tweet.
