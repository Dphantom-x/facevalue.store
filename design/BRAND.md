# FaceValue — Brand & Visual Direction

## Name & voice
- **FaceValue** — the name carries both halves: tickets at *face value* (no gouging) and *face* /
  identity verification (proof you're one real person).
- Tagline: **"Real fans. Real tickets. Face value."**
- Voice: confident, modern, fan-first, quietly defiant toward scalpers. Credible to both a concert
  fan and a sponsor/VC judge. Not crypto-bro, not corporate-stiff.

## Color direction (suggestions — Tailwind v4 HSL tokens in `globals.css`)
- **Verified / fan / success:** emerald/green — the hero color. The feeling of "you got in, fairly."
- **Scalper / blocked / danger:** red — the swarm bouncing off the gate.
- **Ink / text:** near-black, high contrast, confident.
- **Accent:** one strong, trustworthy accent (a deep electric blue or violet works) for CTAs and the
  "verified" motif. Avoid neon-everything; let green/red do the storytelling.
- **Surface:** clean light canvas; optional dark mode for the simulation to make tiles pop.

## Motifs to lean into
- **"Face value $X ✓"** chip — recurring, reassuring, anti-gouge.
- **Verified-human badge** — World ID / proof-of-personhood mark; one-human-one-ticket.
- **Red-vs-green contrast** — scalper swarm vs verified fan. This is the emotional core; use it on the
  simulation and wherever the two outcomes appear.
- **Identity-bound ticket** — the ticket as something locked to a person, non-transferable (a seal/lock motif).
- **"Built on Valiron"** — a small, credible trust mark (sponsor presence).

## Typography
- A clean, confident sans for UI/body. A characterful display face for headlines is welcome (the
  reference Claude Design projects used Geist + an editorial serif accent — same spirit is fine).
- Numbers (face value, ticket counts, scores) should feel precise — a tabular/mono touch for stats is nice.

## Feeling per screen
- **Home:** bold, declarative, "we fixed scalping."
- **Simulation:** dynamic, a little tense → resolving to fairness. The live Valiron panel = hard proof.
- **Fan:** premium and reassuring — verification feels like a velvet rope that's on *your* side.
- **Vendor:** a crisp, trustworthy dashboard a promoter would actually deploy.
